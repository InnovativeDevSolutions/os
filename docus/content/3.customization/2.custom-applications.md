# Creating Custom Applications

This guide covers how to create custom applications for the Forge OS desktop environment. You'll learn how to build both **system applications** (native OS apps) and **web applications** (browser-based apps) using the existing framework.

## Overview

Forge OS supports two types of applications:

| Type | Description | Use Cases | Examples |
|------|-------------|-----------|----------|
| **System Apps** | Standalone windows with full OS integration | Document editors, media viewers, file browsers | Notepad, Calendar, SNet |
| **Web Apps** | Browser-based apps running inside Internet Explorer | Interactive dashboards, forms, data viewers | Intranet, Mail |

## Architecture

All applications in Forge OS extend the base `Window` class, which provides:

- Window management (minimize, maximize, close)
- Drag and drop functionality
- Taskbar integration
- Event handling
- Content rendering

## Creating a System Application

System applications are JavaScript classes that extend the `Window` base class and provide their own UI and functionality.

### Application Structure

```javascript
class YourApp extends Window {
    constructor() {
        super({
            title: 'Your App Name',
            icon: 'FORGE_FX_Desktop_Ico_YourIcon_CA',
            width: 800,
            height: 600
        });
        
        this.element.classList.add('yourapp-window');
        this.initializeApp();
    }
    
    initializeApp() {
        // Your initialization code
    }
}

// Register globally
window.YourApp = YourApp;
```

#### 2. Write Your Application Class

Here's a complete example of a simple Notes application:

```javascript path=null start=null
/**
 * Notes Application
 * Simple note-taking app with list view
 */
class Notes extends Window {
    constructor() {
        super({
            title: 'Notes',
            icon: 'FORGE_FX_Desktop_Ico_Notepad01_CA',
            width: 700,
            height: 500
        });
        
        this.element.classList.add('notes-window');
        this.notes = [];
        this.selectedNoteId = null;
        
        this.initializeNotes();
        this.loadNotes();
    }
    
    initializeNotes() {
        const windowBody = this.element.querySelector('.window-body');
        windowBody.innerHTML = `
            <div class="notes-layout">
                <div class="notes-sidebar">
                    <button class="new-note-btn">New Note</button>
                    <div class="notes-list"></div>
                </div>
                <div class="notes-editor">
                    <input type="text" class="note-title" placeholder="Note Title">
                    <textarea class="note-content" placeholder="Start typing..."></textarea>
                </div>
            </div>
        `;
        
        this.setupEventHandlers();
        this.setupStatusBar();
    }
    
    setupEventHandlers() {
        // New note button
        this.element.querySelector('.new-note-btn').addEventListener('click', () => {
            this.createNote();
        });
        
        // Auto-save on input
        const titleInput = this.element.querySelector('.note-title');
        const contentInput = this.element.querySelector('.note-content');
        
        titleInput.addEventListener('input', () => this.saveCurrentNote());
        contentInput.addEventListener('input', () => this.saveCurrentNote());
    }
    
    setupStatusBar() {
        const statusBar = this.element.querySelector('.status-bar');
        statusBar.innerHTML = `
            <div class='status-bar-field'>Ready</div>
            <div class='status-bar-field'>Notes: ${this.notes.length}</div>
        `;
    }
    
    createNote() {
        const note = {
            id: Date.now(),
            title: 'Untitled Note',
            content: '',
            created: new Date().toISOString()
        };
        
        this.notes.push(note);
        this.renderNotesList();
        this.selectNote(note.id);
        this.saveNotes();
    }
    
    selectNote(noteId) {
        this.selectedNoteId = noteId;
        const note = this.notes.find(n => n.id === noteId);
        
        if (note) {
            this.element.querySelector('.note-title').value = note.title;
            this.element.querySelector('.note-content').value = note.content;
            
            // Highlight selected note in list
            this.element.querySelectorAll('.note-item').forEach(item => {
                item.classList.toggle('selected', item.dataset.id == noteId);
            });
        }
    }
    
    saveCurrentNote() {
        if (!this.selectedNoteId) return;
        
        const note = this.notes.find(n => n.id === this.selectedNoteId);
        if (note) {
            note.title = this.element.querySelector('.note-title').value;
            note.content = this.element.querySelector('.note-content').value;
            this.saveNotes();
            this.renderNotesList();
        }
    }
    
    renderNotesList() {
        const notesList = this.element.querySelector('.notes-list');
        notesList.innerHTML = this.notes.map(note => `
            <div class="note-item ${note.id === this.selectedNoteId ? 'selected' : ''}" 
                 data-id="${note.id}">
                <div class="note-item-title">${note.title}</div>
                <div class="note-item-date">${new Date(note.created).toLocaleDateString()}</div>
            </div>
        `).join('');
        
        // Click handlers for note items
        notesList.querySelectorAll('.note-item').forEach(item => {
            item.addEventListener('click', () => {
                this.selectNote(parseInt(item.dataset.id));
            });
        });
        
        this.setupStatusBar();
    }
    
    saveNotes() {
        // Save to Arma 3 profile namespace
        A3Bridge.sendCommand('saveNotes', { notes: this.notes });
    }
    
    loadNotes() {
        // Load from Arma 3 profile namespace
        A3Bridge.sendCommand('loadNotes', {});
    }
    
    // Called by Arma when notes are loaded
    onNotesLoaded(data) {
        this.notes = data.notes || [];
        this.renderNotesList();
        if (this.notes.length > 0) {
            this.selectNote(this.notes[0].id);
        }
    }
}

// Register globally so OS can instantiate it
window.Notes = Notes;
```

#### 4. Register in config.js

Add your application to the system applications registry in `Win99UI/js/config.js`:

```javascript path=null start=null
applications: {
    system: {
        notepad: {
            files: ['apps\\notepad.js'],
            class: 'Notepad'
        },
        // ... other apps
        
        // Add your new app
        notes: {
            files: ['apps\\myapp.js'],  // Path to your JS file
            class: 'Notes'               // Your class name
        }
    }
}
```

If you have a CSS file, you can load it separately or inline it in your JavaScript.

## Creating a Web Application

Web applications run inside the Internet Explorer browser window and use HTML/CSS/JavaScript.

### Web App Structure

```javascript
class YourWebApp {
    constructor(container) {
        this.container = container;
        this.state = {};
        this.init();
    }
    
    init() {
        this.render();
        this.setupEventHandlers();
    }
    
    render() {
        this.container.innerHTML = `
            <!-- Your HTML here -->
        `;
    }
    
    setupEventHandlers() {
        // Event handlers
    }
}

window.YourWebApp = YourWebApp;
```

### Step-by-Step Guide

#### 1. Create App Files

Create JavaScript and CSS files in `Win99UI/apps/webapps/`:

```
mpmissions/os_bare.VR/Win99UI/apps/webapps/dashboard.js
mpmissions/os_bare.VR/Win99UI/apps/webapps/dashboard.css
```

#### 2. Write Your Web App

Example dashboard application:

```javascript path=null start=null
/**
 * Dashboard Web Application
 * Displays operational statistics and quick links
 */
class DashboardApp {
    constructor(container) {
        this.container = container;
        this.state = {
            stats: {
                activeMissions: 0,
                onlinePersonnel: 0,
                pendingReports: 0
            }
        };
        
        this.init();
    }
    
    init() {
        this.render();
        this.setupEventHandlers();
        this.loadData();
    }
    
    render() {
        this.container.innerHTML = `
            <div class="dashboard">
                <header class="dashboard-header">
                    <h1>Operations Dashboard</h1>
                    <div class="timestamp">${new Date().toLocaleString()}</div>
                </header>
                
                <div class="stats-grid">
                    <div class="stat-card">
                        <div class="stat-value">${this.state.stats.activeMissions}</div>
                        <div class="stat-label">Active Missions</div>
                    </div>
                    <div class="stat-card">
                        <div class="stat-value">${this.state.stats.onlinePersonnel}</div>
                        <div class="stat-label">Online Personnel</div>
                    </div>
                    <div class="stat-card">
                        <div class="stat-value">${this.state.stats.pendingReports}</div>
                        <div class="stat-label">Pending Reports</div>
                    </div>
                </div>
                
                <div class="quick-actions">
                    <h2>Quick Actions</h2>
                    <button class="action-btn" data-action="newReport">Create Report</button>
                    <button class="action-btn" data-action="viewIntel">View Intel</button>
                    <button class="action-btn" data-action="openComms">Communications</button>
                </div>
                
                <div class="recent-activity">
                    <h2>Recent Activity</h2>
                    <div class="activity-list"></div>
                </div>
            </div>
        `;
    }
    
    setupEventHandlers() {
        this.container.querySelectorAll('.action-btn').forEach(btn => {
            btn.addEventListener('click', (e) => {
                const action = e.target.dataset.action;
                this.handleAction(action);
            });
        });
    }
    
    handleAction(action) {
        switch(action) {
            case 'newReport':
                console.log('Creating new report...');
                break;
            case 'viewIntel':
                window.os.openApp('snet');
                break;
            case 'openComms':
                window.os.openApp('messenger');
                break;
        }
    }
    
    loadData() {
        // Request data from Arma backend
        A3Bridge.sendCommand('getDashboardStats', {});
    }
    
    updateStats(data) {
        this.state.stats = data;
        this.render();
        this.setupEventHandlers();
    }
}

window.DashboardApp = DashboardApp;
```

## Backend Integration

Applications can communicate with the Arma 3 backend using the `A3Bridge` API.

### Sending Commands to Arma

```javascript path=null start=null
// Send a command to Arma
A3Bridge.sendCommand('commandName', { 
    param1: 'value1',
    param2: 'value2'
});
```

### Receiving Data from Arma

Define callback methods in your app class:

```javascript path=null start=null
class MyApp extends Window {
    // ... constructor and other methods
    
    // This method will be called from Arma
    onDataReceived(data) {
        console.log('Received data:', data);
        this.updateUI(data);
    }
}
```

### Example: Calendar Events

The Calendar app demonstrates full backend integration:

```javascript path=null start=null
// In Calendar.js
createEvent(eventData) {
    // Send to backend
    A3Bridge.sendCommand('calendar_createEvent', eventData);
}

// Callback from backend
onEventCreated(data) {
    this.events.push(data.event);
    this.renderCalendar();
}
```

## Best Practices

### Application Design

- **Keep it focused**: One app = one purpose
- **Use components**: Break UI into reusable pieces
- **Handle errors**: Gracefully handle missing data or failed operations
- **Provide feedback**: Update status bars, show loading states

### Performance

- **Lazy load media**: Load images/videos only when needed
- **Debounce inputs**: Don't send every keystroke to backend
- **Cache data**: Store frequently accessed data in memory
- **Clean up**: Remove event listeners when windows close

### Code Organization

```javascript path=null start=null
class WellOrganizedApp extends Window {
    constructor() {
        super({ /* config */ });
        this.initializeState();
        this.initializeUI();
        this.loadData();
    }
    
    // State management
    initializeState() { }
    
    // UI setup
    initializeUI() { }
    renderMainView() { }
    updateStatusBar() { }
    
    // Event handlers
    setupEventHandlers() { }
    handleButtonClick(event) { }
    
    // Data operations
    loadData() { }
    saveData() { }
    
    // Backend communication
    onDataLoaded(data) { }
    onDataSaved(result) { }
}
```

### Multiplayer Considerations

If your app needs multiplayer sync:

1. **Server-authoritative**: Let the server manage shared state
2. **Use CBA events**: Leverage existing event system
3. **Optimize traffic**: Only sync what's necessary
4. **Handle conflicts**: Plan for concurrent edits

## Testing Your Application

### Local Testing

1. Place your files in the correct directories
2. Register in `config.js`
3. Load the mission in Arma 3 Editor
4. Preview and open the OS
5. Launch your app from Start Menu or desktop

### Debugging

Use the browser console (F12) to debug JavaScript:

```javascript path=null start=null
console.log('Debug message');
console.error('Error occurred:', error);
console.table(this.data);  // Display arrays/objects as tables
```

### Common Issues

::callout{icon="i-lucide-x-circle" color="red"}
**App doesn't appear in Start Menu**
- Verify `config.js` registration
- Check class name matches
- Ensure files are in correct directory
::

::callout{icon="i-lucide-alert-triangle" color="amber"}
**Window doesn't render**
- Check Window constructor parameters
- Verify HTML structure in render methods
- Look for JavaScript errors in console
::

::callout{icon="i-lucide-info" color="blue"}
**Backend commands not working**
- Verify command name matches SQF handler
- Check data format sent to Arma
- Ensure A3Bridge is loaded
::
