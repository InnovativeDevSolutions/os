## Quick Start

### Adding Media to Your Mission

The fastest way to get started is by adding custom media to the SNet Intelligence Center:

1. **Add your files** to the `snet/` directory structure
2. **Convert to base64** using `media_to_base64.exe`
3. **Register in config.js** to make files accessible in SNet
4. **Test in-game** by opening the Intelligence Center

[View Media Management Guide →](/customization/media-management)

### Creating Your First App

Build a simple application in just a few steps:

1. **Create a JS file** in `Win99UI/apps/`
2. **Extend the Window class** with your functionality
3. **Register in config.js** under system applications
4. **Add to Start Menu** for easy access

[View Application Development Guide →](/customization/custom-applications)

## Architecture Overview

Understanding the Forge OS architecture will help you customize effectively:

### Frontend Structure

```
Win99UI/
├── js/
│   ├── config.js          # System configuration
│   ├── main.js            # OS orchestrator
│   ├── loader.js          # Component loader
│   └── a3bridge.js        # Arma-browser bridge
├── apps/
│   ├── *.js               # System applications
│   └── webapps/           # Web applications
├── components/
│   ├── window/            # Window base class
│   ├── desktop/           # Desktop manager
│   ├── taskbar/           # Taskbar component
│   └── startmenu/         # Start menu component
└── styles/                # CSS stylesheets
```

### Configuration System

The `config.js` file is the heart of customization:

- **Start Menu**: Define menu structure and program shortcuts
- **Desktop Icons**: Configure desktop shortcuts and layout
- **Applications**: Register system apps and web apps
- **SNet Filesystem**: Define virtual file system structure

### Component Loading

Forge OS uses a dynamic component loading system:

1. **Base components** load first (overlay, wallpaper, window system)
2. **Applications** are loaded from configuration
3. **UI components** initialize (taskbar, start menu, desktop)
4. **User interaction** begins

## Customization Workflows

### Mission Briefing Workflow

Perfect for mission makers who want to add briefings and intel:

1. Create markdown briefings in `snet/ops/briefings/`
2. Add reference images to `snet/ops/images/`
3. Run `media_to_base64.exe`
4. Update `config.js` with file entries
5. Test by navigating to files in SNet

### Application Development Workflow

For developers creating custom apps:

1. Study existing apps (`notepad.js`, `calendar.js`)
2. Create new app class extending `Window`
3. Implement UI and business logic
4. Add backend SQF handlers if needed
5. Register and test

### UI Theming Workflow

For customizing the visual appearance:

1. Modify CSS files in `Win99UI/styles/`
2. Update icon references in `config.js`
3. Change wallpaper textures
4. Adjust color schemes in component CSS
5. Test across different resolutions

## Best Practices

### Media Files

- **Compress images** before adding (JPEG 80-90% quality)
- **Keep videos short** (< 30 seconds recommended)
- **Use descriptive filenames** with underscores
- **Organize logically** by mission/operation

### Application Development

- **Study existing code** before creating new apps
- **Follow naming conventions** used in existing apps
- **Test thoroughly** in both single-player and multiplayer
- **Handle errors gracefully** with user-friendly messages
- **Document your code** for future maintenance

### Configuration

- **Backup config.js** before major changes
- **Use version control** to track modifications
- **Test incrementally** after each change
- **Keep paths consistent** with directory structure

### Performance

- **Limit base64 file sizes** (< 5MB per file)
- **Lazy load content** when possible
- **Cache frequently accessed data** in memory
- **Minimize DOM manipulations** for smooth UI

## Common Customization Scenarios

### Adding Mission-Specific Intel

**Goal**: Add briefings and images for a specific operation

**Steps**:
1. Create `snet/ops/briefings/operation_name.md`
2. Add supporting images to `snet/ops/images/`
3. Convert with `media_to_base64.exe`
4. Register files in `config.js` under `/ops/briefings` and `/ops/images`

### Creating a Task Management App

**Goal**: Build a simple todo list application

**Steps**:
1. Create `Win99UI/apps/tasks.js` extending Window
2. Implement task list UI with add/delete functionality
3. Add backend storage handlers in SQF
4. Register in `config.js` as system app
5. Add to Start Menu under Programs

### Custom Web Dashboard

**Goal**: Create an operations dashboard in Internet Explorer

**Steps**:
1. Create `Win99UI/apps/webapps/ops_dashboard.js`
2. Design stats display and quick links
3. Style with `ops_dashboard.css`
4. Register as web app in `config.js`
5. Launch via Internet Explorer
