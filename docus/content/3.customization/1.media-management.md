# Media Management

This guide covers how to add, edit, and manage media files (images, videos, audio, markdown documents) for the Forge OS SNet Intelligence Center application.

## Overview

The SNet application uses a virtual file system that stores media files in **base64-encoded format**. This allows the files to be embedded directly in the mission without external dependencies, making them accessible to all players in multiplayer sessions.

### Workflow Summary

1. Add your media files to the appropriate `snet/` directory
2. Run `media_to_base64.exe` to convert files to base64 format
3. Update `config.js` to register the new files in the SNet file system
4. Test the media in-game via the SNet application

## Directory Structure

All media files are stored in the `mpmissions/os_bare.VR/snet/` directory:

```
snet/
├── intel/               # Intelligence Division
│   ├── images/
│   └── reports/
├── ops/                 # Operations Center
│   ├── audio/          # Audio files (MP3)
│   ├── briefings/      # Markdown documents
│   ├── images/         # Images (JPG, PNG)
│   ├── orders/
│   ├── training/
│   └── videos/         # Videos (WebM)
└── surveillance/        # Surveillance Hub
    ├── analytics/
    ├── live/
    ├── photos/
    └── recordings/
```

## Adding Media Files

### Step 1: Place Your Media Files

Add your original media files to the appropriate subdirectory:

::code-group
  ```bash [Images]
  # Place images in the images folder
  mpmissions/os_bare.VR/snet/ops/images/mission_map.jpg
  mpmissions/os_bare.VR/snet/intel/images/satellite_view.png
  ```

  ```bash [Videos]
  # Place videos in the videos folder (WebM format recommended)
  mpmissions/os_bare.VR/snet/ops/videos/training_video.webm
  ```

  ```bash [Audio]
  # Place audio files in the audio folder
  mpmissions/os_bare.VR/snet/ops/audio/comms_recording.mp3
  ```

  ```bash [Markdown]
  # Place markdown documents in the briefings folder
  mpmissions/os_bare.VR/snet/ops/briefings/operation_overview.md
  ```
::

::callout{icon="i-lucide-info" color="blue"}
**Supported File Types:**
- **Images**: JPG, PNG
- **Videos**: WebM (H.264/VP8 codec)
- **Audio**: MP3
- **Documents**: Markdown (.md)
::

### Step 2: Organize by Category

Choose the appropriate directory based on the content type:

| Directory | Purpose | Examples |
|-----------|---------|----------|
| `/intel/images` | Intelligence photos and maps | Satellite imagery, terrain maps, target photos |
| `/ops/briefings` | Mission briefings and docs | Operation orders, tactical plans |
| `/ops/images` | Operational imagery | Reference images, equipment photos |
| `/ops/videos` | Training and mission videos | Instructional content, mission recordings |
| `/ops/audio` | Audio recordings | Radio communications, briefings |
| `/surveillance/photos` | Surveillance imagery | Reconnaissance photos, security footage |

## Converting Media to Base64

The `media_to_base64.exe` tool converts all media files in the `snet/` directory to base64-encoded format.

### Location

The conversion tool is located at:
```
mpmissions/os_bare.VR/tools/media_to_base64.exe
```

**Supported File Types:**
- **Images**: `.png`, `.jpg`, `.jpeg`
- **Audio**: `.mp3`
- **Video**: `.mp4`, `.webm`
- **Documents**: `.md` (markdown)

### Running the Converter

::code-group
  ```bash [Windows (PowerShell)]
  # Navigate to the mission directory
  cd F:\IDSolutions\forge_os\mpmissions\forge_os_bare.VR

  # Run the converter
  .\tools\media_to_base64.exe
  
  # When prompted, enter:
  # .. (two periods) - Process recursively (recommended)
  # . (single period) - Process current directory only
  ```

  ```bash [Windows (Command Prompt)]
  # Navigate to the mission directory
  cd F:\IDSolutions\forge_os\mpmissions\forge_os_bare.VR

  # Run the converter
  tools\media_to_base64.exe
  
  # When prompted, enter:
  # .. (two periods) - Process recursively (recommended)
  # . (single period) - Process current directory only
  ```

  ```bash [Python Script]
  # If using the Python script directly
  cd F:\IDSolutions\forge_os\mpmissions\forge_os_bare.VR\tools
  
  python media_to_base64.py
  
  # When prompted, enter:
  # .. (two periods) - Process recursively (recommended)
  # . (single period) - Process current directory only
  ```
::

### What the Converter Does

The tool will prompt you for input:

| Input | Behavior |
|-------|----------|
| `..` (two periods) | Process current directory AND all subdirectories recursively |
| `.` (single period) | Process current directory only (one layer, non-recursive) |
| Specific path | Process files from specified path (recursive by default) |
| File path | Process single file |

::callout{icon="i-lucide-alert-circle" color="amber"}
**Important:** The `..` input does NOT navigate to parent directory. It enables recursive processing within your current directory.
::

The converter then:

1. **Scans** the specified directory for supported media files
2. **Encodes** each file to base64 format
3. **Creates** `.b64` files alongside the originals
4. **Preserves** the original files (non-destructive)

::callout{icon="i-lucide-check-circle" color="green"}
**Example Output:**
```
snet/ops/images/promo.jpg          # Original file (kept)
snet/ops/images/promo.jpg.b64      # Base64 encoded version (created)
```
::

### Expected Output

When you run the converter, you'll see an interactive prompt:

```
Enter the path to your media file or folder: ..
```

After entering `..` (for recursive processing), you'll see:

```
Converted snet\ops\images\mission_map.jpg to base64 -> snet\ops\images\mission_map.jpg.b64
Converted snet\ops\videos\briefing.webm to base64 -> snet\ops\videos\briefing.webm.b64
Converted snet\ops\briefings\operation.md to base64 -> snet\ops\briefings\operation.md.b64

Conversion complete! 3 files processed.
```

::callout{icon="i-lucide-alert-triangle" color="amber"}
**Important:** The converter creates `.b64` files but does NOT modify your original media files. You can safely re-run the converter at any time.
::

## Updating the SNet File System

After converting your media to base64, you need to register the files in the `config.js` file so the SNet application can find them.

### Location

The configuration file is located at:
```
mpmissions/os_bare.VR/Win99UI/js/config.js
```

### File Entry Structure

Each file entry in the SNet file system requires these properties:

```javascript
{
    name: 'display_name.ext',           // Display name shown in SNet
    type: 'media',                       // File type (media or directory)
    fileType: 'image/jpeg',              // MIME type
    path: '/ops/images/display_name.ext', // Virtual path in SNet
    relativePath: 'snet\\ops\\images\\display_name.ext.b64' // Physical path to .b64 file
}
```

::callout{icon="i-lucide-info" color="blue"}
**Note:** Use double backslashes (`\\`) in the `relativePath` for Windows paths.
::

### Adding Files to config.js

Edit the `snetFilesystem` section in `config.js`:

::code-group
  ```javascript [Adding an Image]
  '/ops/images': [
      // Existing files...
      {
          name: 'promo.jpg',
          type: 'media',
          fileType: 'image/jpeg',
          path: '/ops/images/promo.jpg',
          relativePath: 'snet\\ops\\images\\promo.jpg.b64'
      },
      // Add your new image
      {
          name: 'mission_map.jpg',
          type: 'media',
          fileType: 'image/jpeg',
          path: '/ops/images/mission_map.jpg',
          relativePath: 'snet\\ops\\images\\mission_map.jpg.b64'
      }
  ]
  ```

  ```javascript [Adding a Video]
  '/ops/videos': [
      // Existing files...
      {
          name: 'promo.webm',
          type: 'media',
          fileType: 'video/webm',
          path: '/ops/videos/promo.webm',
          relativePath: 'snet\\ops\\videos\\promo.webm.b64'
      },
      // Add your new video
      {
          name: 'training.webm',
          type: 'media',
          fileType: 'video/webm',
          path: '/ops/videos/training.webm',
          relativePath: 'snet\\ops\\videos\\training.webm.b64'
      }
  ]
  ```

  ```javascript [Adding Audio]
  '/ops/audio': [
      // Add your audio file
      {
          name: 'briefing_audio.mp3',
          type: 'media',
          fileType: 'audio/mp3',
          path: '/ops/audio/briefing_audio.mp3',
          relativePath: 'snet\\ops\\audio\\briefing_audio.mp3.b64'
      }
  ]
  ```

  ```javascript [Adding Markdown]
  '/ops/briefings': [
      // Add your markdown document
      {
          name: 'operation_plan.md',
          type: 'media',
          fileType: 'text/markdown',
          path: '/ops/briefings/operation_plan.md',
          relativePath: 'snet\\ops\\briefings\\operation_plan.md.b64'
      }
  ]
  ```
::

### MIME Types Reference

| File Extension | MIME Type |
|---------------|-----------|
| `.jpg`, `.jpeg` | `image/jpeg` |
| `.png` | `image/png` |
| `.webm` | `video/webm` |
| `.mp3` | `audio/mp3` |
| `.md` | `text/markdown` |

### Creating New Directories

If you need to add a new directory to the SNet file system:

```javascript
// 1. Add the directory to its parent
'/ops': [
    { name: 'Audio', type: 'directory', path: '/ops/audio' },
    { name: 'Briefings', type: 'directory', path: '/ops/briefings' },
    { name: 'Images', type: 'directory', path: '/ops/images' },
    { name: 'Videos', type: 'directory', path: '/ops/videos' },
    // Add new directory
    { name: 'Maps', type: 'directory', path: '/ops/maps' }
],

// 2. Create the directory's file list
'/ops/maps': [
    {
        name: 'tactical_map.jpg',
        type: 'media',
        fileType: 'image/jpeg',
        path: '/ops/maps/tactical_map.jpg',
        relativePath: 'snet\\ops\\maps\\tactical_map.jpg.b64'
    }
]
```

## Testing Your Media

### In Arma 3 Editor

1. Open the mission in Arma 3 Editor
2. Preview the mission
3. Interact with a keyboard object
4. Select "Open OS" from the ACE interaction menu
5. Launch the **Intelligence Center** from the desktop
6. Navigate to the directory containing your media
7. Click on your file to preview it

### Common Issues

::callout{icon="i-lucide-x-circle" color="red"}
**File Not Found**
- Verify the `relativePath` in `config.js` matches the actual `.b64` file path
- Check for typos in file names or directory paths
- Ensure you ran `media_to_base64.exe` after adding the files
::

::callout{icon="i-lucide-alert-triangle" color="amber"}
**Media Not Loading**
- Verify the `fileType` (MIME type) is correct
- For videos, ensure WebM format with compatible codec
- Check browser console for JavaScript errors (F12 in preview)
::

::callout{icon="i-lucide-info" color="blue"}
**Large File Sizes**
- Base64 encoding increases file size by ~33%
- Keep videos short (under 30 seconds recommended)
- Compress images before adding them
- Mission file size impacts loading times
::

## Best Practices

### File Naming

- Use **lowercase** with **underscores** or **hyphens**
- Avoid spaces and special characters
- Be descriptive: `operation_redwood_briefing.md` vs `brief.md`

### File Organization

- Keep related files in the same directory
- Use subdirectories for different operations/missions
- Maintain a logical hierarchy (intel, ops, surveillance)

### Performance

- **Compress images** before adding (JPEG quality 80-90%)
- **Optimize videos** to web-friendly bitrates
- **Limit individual file sizes** (< 5MB per file recommended)
- Keep total mission size under 100MB for multiplayer

### Version Control

- Keep original files in a separate backup folder
- Document changes in a changelog
- Test thoroughly before deploying to multiplayer

## Example Workflow

Here's a complete example of adding a mission briefing:

1. **Create the markdown file:**
   ```bash
   # File: snet/ops/briefings/operation_eagle.md
   ```
   ```markdown
   # Operation Eagle
   
   ## Objective
   Neutralize enemy communications facility
   
   ## Intel Summary
   - Location: Grid 045-123
   - Enemy Strength: 20-30 combatants
   - Time: 0200 hours
   ```

2. **Convert to base64:**
   ```bash
   .\tools\media_to_base64.exe
   # When prompted, enter: ..
   # Creates: snet/ops/briefings/operation_eagle.md.b64
   ```

3. **Update config.js:**
   ```javascript
   '/ops/briefings': [
       {
           name: 'operation_eagle.md',
           type: 'media',
           fileType: 'text/markdown',
           path: '/ops/briefings/operation_eagle.md',
           relativePath: 'snet\\ops\\briefings\\operation_eagle.md.b64'
       }
   ]
   ```

4. **Test in Arma 3:**
   - Load mission → Open OS → Intelligence Center → Operations → Briefings
   - Click on "operation_eagle.md"
   - Verify markdown renders correctly with formatting
