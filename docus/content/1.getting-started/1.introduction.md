# Introduction to Forge OS

Welcome to **Forge OS** - a fully functional Windows 98/99-style operating system interface for Arma 3. Transform your missions with an immersive computer terminal experience complete with draggable windows, functional applications, and seamless multiplayer integration.

## What is Forge OS?

Forge OS brings a vintage computing experience into the Arma 3 game world. Players can interact with in-game computer terminals featuring a complete desktop environment, multiple applications, and real-time multiplayer synchronization.

::callout{icon="i-lucide-tv" color="blue"}
**Perfect for role-playing scenarios, mission briefings, intelligence coordination, and immersive gameplay experiences.**
::

## Key Features

### 🖥️ Desktop Environment

- **Authentic Windows 98/99 aesthetic** with retro UI elements
- **Window management system** - Drag, resize, minimize, maximize windows
- **Start menu** with organized program categories
- **Taskbar** with active window tracking and system tray
- **Desktop shortcuts** with customizable icons
- **Wallpaper system** with texture support

### 📱 Built-in Applications

#### System Applications

- **Notepad** - Create, edit, and save text files with persistent storage
- **Calendar** - Event management with date/time scheduling
- **Messenger** - Real-time multiplayer chat with status indicators
- **Internet Explorer** - In-game web browser for custom applications
- **SNet Intelligence Center** - Mission briefings, intel docs, media viewer

#### Web Applications

- **Intranet Portal** - Organizational dashboard with notifications
- **Mail Client** - Email-style messaging system

### 🌐 Multiplayer Features

- **Synchronized player chat** across all connected clients
- **Real-time status updates** for all players
- **Shared calendar events** visible to team members
- **CBA event system** for efficient networking
- **Server-authoritative** player tracking

### 🎨 Customization

- **Add custom media** - Images, videos, audio, markdown documents
- **Create applications** - Build your own system and web apps
- **Modify UI** - Customize desktop, icons, and themes
- **Mission-specific content** - Tailor briefings and intel for your operations

## How It Works

### Architecture

Forge OS uses a hybrid architecture combining Arma 3's SQF scripting language with modern web technologies:

```
┌─────────────────────────────────────┐
│         Arma 3 (Backend)            │
│     SQF Scripts + CBA Events        │
└──────────────┬──────────────────────┘
               │ JSDialog Bridge
┌──────────────▼──────────────────────┐
│    Browser (Frontend - CEF)         │
│  HTML/CSS/JavaScript + Win99UI      │
└─────────────────────────────────────┘
```

**Backend (SQF)**:
- Persistent data storage via profile namespace
- Multiplayer synchronization with CBA events
- Server-authoritative state management
- File loading and resource management

**Frontend (JavaScript)**:
- Window management and UI rendering
- Application logic and event handling
- Component-based architecture
- Dynamic content loading

**Bridge (A3Bridge)**:
- Bi-directional communication
- Command routing and callbacks
- File loading from Arma file system
- Icon and resource loading

## Technology Stack

| Layer | Technology |
|-------|-----------|
| **Backend** | SQF (Arma 3 scripting language) |
| **Frontend** | HTML5, CSS3, JavaScript ES6+ |
| **Bridge** | Arma 3 ↔ CEF browser communication |
| **UI Framework** | Custom Win99UI components |
| **State Management** | HashMapObject pattern |
| **Networking** | CBA event system |
| **Storage** | Profile namespace (client-side) |

## Quick Start

1. **Subscribe to required mods** on Steam Workshop
2. **Enable mods** in Arma 3 Launcher
3. **Load the mission** `forge_os_bare.VR` from Virtual Reality map
4. **Approach a keyboard** object in-game
5. **Use ACE interaction** (Windows key) and select "Open OS"
6. **Explore the desktop** and launch applications
