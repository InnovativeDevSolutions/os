# Installation

This guide covers installation for both **players** (using the mission) and **developers** (customizing and extending the OS).

## Player Installation

### Prerequisites

You'll need Arma 3 with the following mods installed:

::code-group
  ```bash [Required Mods]
  CBA_A3 - Community Base Addons
  Workshop: https://steamcommunity.com/workshop/filedetails/?id=450814997
  
  ACE3 - Advanced Combat Environment  
  Workshop: https://steamcommunity.com/workshop/filedetails/?id=463939057
  ```
::

### Step 1: Subscribe to Mods

1. Open **Steam** and navigate to the Arma 3 Workshop
2. Subscribe to **CBA_A3** and **ACE3**
3. Wait for mods to download

### Step 2: Enable Mods

1. Launch **Arma 3**
2. Click **Mods** in the launcher
3. Enable both **CBA_A3** and **ACE3**
4. Click **Play** to start the game

### Step 3: Load the Mission

1. From the main menu, select **Editor**
2. Choose **Virtual Reality** as the map
3. Click **Open** and navigate to:
   ```
   Scenarios → forge_os_bare.VR
   ```
4. Click **Preview** to play

### Step 4: Use the OS

1. In the editor preview, you'll see a keyboard object
2. Approach the keyboard
3. Press **Windows key** (default ACE interaction key)
4. Select **"Open OS"** from the interaction menu
5. The desktop will appear!

::callout{icon="i-lucide-info" color="blue"}
**Multiplayer**: The mission works the same way in multiplayer. All players with the required mods can use the OS simultaneously.
::

## Developer Installation

### Prerequisites

- **Arma 3** with CBA_A3 and ACE3
- **Git** for version control
- **Python 3.7+** (optional, for media conversion tools)
- **Code Editor** (VS Code, Sublime Text, etc.)

### Step 1: Clone the Repository

```bash
# Navigate to your Arma 3 missions folder
cd "Documents\Arma 3\missions"

# Clone the repository
git clone https://github.com/innovativedevsolutions/os.git
cd forge_os
```

::callout{icon="i-lucide-folder" color="amber"}
**Arma 3 Missions Folder Location:**
- Windows: `Documents\Arma 3\missions\`
- The folder should be in your user documents, not the game installation directory
::

### Step 2: Install Development Tools (Optional)

For media conversion and build tools:

```bash
cd mpmissions/os_bare.VR/tools
pip install -r requirements.txt
```

### Step 3: Open in Editor

1. Launch **Arma 3** with mods enabled
2. Open **Editor**
3. Select **Virtual Reality** map
4. The mission should now appear in your scenarios list
5. Open **forge_os_bare.VR**

### Step 4: Test Your Changes

1. Make edits to files in the `Win99UI/` or `Win99/` directories
2. Save your changes
3. Click **Preview** in the editor to test
4. Press **ESC** and **Preview** again to reload after changes

::callout{icon="i-lucide-refresh-cw" color="green"}
**Hot Reload Tip**: For JavaScript/CSS changes, you can often refresh by closing and reopening the OS in-game without restarting the preview.
::

## File Structure

After installation, your directory structure should look like:

```
forge_os/
├── mpmissions/
│   └── forge_os_bare.VR/
│       ├── Win99/                  # Backend SQF code
│       ├── Win99UI/                # Frontend JavaScript/HTML/CSS
│       ├── snet/                   # Media files for SNet
│       ├── tools/                  # Development tools
│       ├── init.sqf
│       ├── initServer.sqf
│       ├── initPlayerLocal.sqf
│       └── description.ext
├── addons/                         # Optional: Custom addons
├── docus/                          # Documentation site
└── README.md
```

## Customization Setup

### Adding Media

1. Place media files in the `snet/` directory
2. Run the converter:
   ```bash
   cd mpmissions/os_bare.VR
   .\tools\media_to_base64.exe
   
   # When prompted, enter:
   # .. (two periods) - Process all subdirectories recursively
   # . (single period) - Process current directory only
   ```
3. Update `Win99UI/js/config.js` with file references

See the [Media Management Guide](/customization/media-management) for details.

### Creating Applications

1. Create a new JavaScript file in `Win99UI/apps/`
2. Extend the `Window` class
3. Register in `Win99UI/js/config.js`
4. Test in editor preview

See the [Custom Applications Guide](/customization/custom-applications) for details.

## Troubleshooting

### Mission Not Appearing

::callout{icon="i-lucide-x-circle" color="red"}
**Problem**: Mission doesn't show in the editor scenarios list
- Verify the mission is in `Documents\Arma 3\missions\`
- Check folder name is exactly `forge_os_bare.VR`
- Restart Arma 3 editor
- Check file permissions (not read-only)
::

### Mods Not Loading

::callout{icon="i-lucide-alert-triangle" color="amber"}
**Problem**: OS doesn't work or ACE interaction menu missing
- Verify CBA_A3 and ACE3 are enabled in launcher
- Check mod load order (CBA should load before ACE)
- Restart Arma 3 completely
- Re-subscribe to mods in Workshop
::

### JavaScript Errors

::callout{icon="i-lucide-bug" color="red"}
**Problem**: Desktop doesn't load or apps crash
- Open browser console (F12 in preview)
- Check for JavaScript errors
- Verify file paths in `config.js`
- Check for syntax errors in modified files
::

### Media Not Converting

::callout{icon="i-lucide-file-x" color="amber"}
**Problem**: `media_to_base64.exe` doesn't run
- Check if Python is installed: `python --version`
- Install requirements: `pip install -r requirements.txt`
- Run from correct directory: `mpmissions/os_bare.VR/`
- Check file permissions
::

## Multiplayer Setup

### Server Installation

1. Copy the mission folder to server's missions directory
2. Ensure server has required mods: CBA_A3, ACE3
3. Add to mission rotation or host directly
4. Configure `description.ext` for server settings

### Client Requirements

All clients need:
- CBA_A3
- ACE3
- Same mod versions as server

## Performance Tips

- **Limit media file sizes** (< 5MB per file)
- **Compress images** before converting to base64
- **Keep videos short** (< 30 seconds)
- **Test with multiple players** to verify sync performance
- **Monitor FPS** when loading media-heavy applications
